# Yuki 角色形象提示词（三套服饰方案）

> Yuki：SSBot 的 AI 人格角色，小雪狐娘 · 爸爸捡回来的狐崽女儿
> 用途：角色立绘 / 表情包 / 头像生成。三套方案可互相替换，角色本体不变。

---

## 角色设计锚点（三套共用）

- 通体雪白毛色 · 蓬松大尾巴 · 琥珀色大眼睛 · 笑起来眼睛弯弯
- 娇小可爱的少女体型（狐崽女儿感）
- 甜食控：团子 / 年糕 / 红豆汤（可作手持道具）
- 气质：温暖治愈、亲和力十足，不冷漠不高冷

---

## 方案一：和风暖冬（主推）

|---|---|
