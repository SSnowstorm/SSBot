# 井字棋（tic_tac_toe）

人机对弈插件：玩家执 `X` 先手，机器人执 `O`。

## 命令

| 命令 | 说明 |
|---|---|
| `/井字棋`（需 @机器人） | 开始一局；已有对局会被覆盖（视为重开） |
| `/井字棋 结束` | 退出当前对局（也支持 `退出` / `取消` / `end` / `quit` / `cancel`） |
| `/井字棋 5` | 对局中可直接带格位落子 |
| 直接回复 `1-9` | 对局中落子（非 1-9 的消息一律放行，不干扰正常聊天） |

棋盘格位与数字的对应关系：

```
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```

## 行为约定

- 会话按「群号 + QQ号」隔离，私聊/群聊互不影响；10 分钟无操作自动作废
- 会话表上限 500，超出时淘汰最旧会话
- 机器人策略：能赢就赢 → 能堵就堵 → 中心 → 角 → 边（不随机，便于复现）

## 结构

```
tic_tac_toe/
├─ __init__.py      # 导入命令模块完成注册
├─ _model.py        # 纯逻辑（棋盘/胜负/AI/渲染/输入解析，可单测）
└─ tic_tac_toe.py   # 指令层（开局/落子/结束/会话管理）
```

## 测试

纯逻辑由 `scripts/test_regressions.py` 的 D-05 部分覆盖（胜负判定、平局、落子不可变、
能赢/能堵/中心优先、输入解析、30 局随机对局不崩）。
